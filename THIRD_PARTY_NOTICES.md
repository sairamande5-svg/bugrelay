# Third-party dependencies

Package versions and transitive dependencies are locked in `package-lock.json`. Installed packages include their upstream license files.

| Dependency | License |
| --- | --- |
| Express | MIT |
| React and React DOM | MIT |
| Zod | MIT |
| Vite | MIT |
| esbuild | MIT |
| Playwright | Apache-2.0 |
| TypeScript | Apache-2.0 |
| DefinitelyTyped type declarations | MIT |

The optional Docker image includes Node.js and Playwright-managed Chromium. Browser distributions include their own third-party notices.
